# ⌚ Wristora - Watch Store Website

A modern desktop-based watch store website built using HTML, CSS, and JavaScript. This project provides a clean and interactive shopping interface where users can browse watches, manage a shopping cart, and explore different pages of the website.

---

## 📌 Project Overview

Wristora is a frontend e-commerce website designed to showcase different categories of watches with a modern and user-friendly interface. The project focuses on improving frontend development skills by building a complete multi-page website from scratch.

---

## ✨ Features

- 🏠 Modern Home Page
- ⌚ Watch Products Page
- 🛒 Shopping Cart Interface
- 🔐 Login Page
- 📝 Signup Page
- 📄 About Page
- 📞 Contact Page
- 🌙 Dark Mode
- 🎨 Clean & Interactive UI
- 📱 Smooth Navigation

---

## 🚀 How to Run

1. Download or clone this repository.

```bash
git clone https://github.com/M-Usman-web/Wristora-Watch-Store.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

No installation or additional software is required.
